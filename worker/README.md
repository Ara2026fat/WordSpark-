# wordspark-api — الخادم وقاعدة البيانات

خادم WordSpark وقاعدة بياناتها، **منفصلان تمامًا** عن `zahim-db` و`ufuq-db`.
تطبيق واحد ← قاعدة واحدة ← Worker واحد، حتى لا يصل خطأ في أحدها إلى غيره أبدًا.

| | |
|---|---|
| قاعدة البيانات | `wordspark-db` |
| المعرّف | `8b4b3d76-565d-4970-a1d4-738f27d97a64` |
| المنطقة | WEUR (فرانكفورت ≈ ٣٥٠٠ كم من الرياض؛ أقرب من سنغافورة بالنصف) |
| الـ Worker | `wordspark-api` |
| التكلفة | **صفر** — ١٠٠ ألف طلب يوميًّا و٥ جيجا مجّانًا |

قاعدة البيانات **مُنشأة والجداول مطبَّقة بالفعل**. الباقي هو نشر الـ Worker.

---

## النشر — أمر واحد

من مجلّد `worker/`:

```bash
npx wrangler login      # مرّة واحدة فقط
npx wrangler deploy
```

يطبع العنوان، ويكون شكله:

```
https://wordspark-api.<حسابك>.workers.dev
```

خذ هذا العنوان وضعه في سطرين:

1. في `index.html` ← `WS_CONFIG.apiUrl`
2. افتح `teacher.html?api=<العنوان>` مرّة واحدة — يُحفظ بعدها

> إن لم يكن `npx` متاحًا عندك: لوحة Cloudflare ← Workers ← Create ← الصق
> محتوى `src/index.js`، ثم Settings ← Bindings ← D1 ← اربط `wordspark-db`
> باسم المتغيّر **`DB`** بالضبط. ومن دون هذا الربط يردّ الخادم برسالة
> «قاعدة البيانات غير مربوطة».

### بعد شراء الدومين

في `wrangler.toml` أزِل التعليق عن `[[routes]]` وضع دومينك، ثم `deploy` مرّة
أخرى. عندها يصبح الـ API على **نفس أصل التطبيق** (`دومينك/api/*`)، فيختفي
موضوع CORS من أساسه بدل أن نعالجه، ويعود `WS_CONFIG.apiUrl` فارغًا إلى الأبد.

وأضِف الدومين إلى `ALLOWED_ORIGINS` في `[vars]`.

## ما الذي يُخزَّن — وما الذي لا يُخزَّن

| يُخزَّن | لا يُخزَّن |
|---|---|
| اسم مستعار يختاره الطالب | الاسم الحقيقي |
| عدد ما أنجزه في كل مسار | إجاباته أو كلماته أو درجاته لكل سؤال |
| وقت آخر نشاط | عنوان IP أو الموقع أو نوع الجهاز |
| نوع ما أُنجز (محطة/قاعدة/…) ووقته | أيّ بريد أو جوّال أو رقم هويّة |

لا توجد حسابات ولا كلمات مرور. للفصل **رمز عامّ** من ٦ حروف يكتبه الطلاب،
و**مفتاح سرّي** يحتفظ به المعلّم. معرفة المفتاح هي ما يجعلك معلّم هذا الفصل،
ومعرفة معرّف الجهاز هي ما يجعلك ذلك الطالب. هذا كلّ شيء.

**والثمن الصريح:** من يفقد المفتاح لا يستعيد الفصل، ويبدأ فصلًا جديدًا.
«استعادة كلمة المرور» تحتاج بريدًا إلكترونيًّا، وبريد إلكتروني من ابن أربعة
عشر عامًا هو بالضبط ما يرفض هذا التصميم أن يحتفظ به. اللوحة تقول ذلك للمعلّم
قبل أن تعرض المفتاح مرّة واحدة.

### الضوابط المطبَّقة فعلًا

- الطالب الذي لا يُدخل رمز فصل **لا يُجري أيّ طلب شبكة إطلاقًا** — مُختبَر.
- الاسم المستعار يُرفض إن حوى `@` أو سلسلة أرقام بطول رقم جوّال. التحذير وحده
  ليس ضابطًا؛ هذان ضابطان.
- النسبة تُحسب **في الخادم** من أعداده هو. عميل معدَّل يرسل `pct: 100` مع ٣
  عناصر منجزة تظهر لوحة المعلّم **٢٪**.
- أصل غير مُدرَج في `ALLOWED_ORIGINS` لا يحصل على ترويسة CORS أصلًا، فلا
  يستطيع موقع آخر قراءة كشف فصل من متصفّح المعلّم.
- حدّ ٦٠ طالبًا للفصل، وحدّ ٨ كيلوبايت للطلب، وسجلّ الأحداث يُقلَّم إلى ٩٠ يومًا
  تلقائيًّا مع كلّ كتابة — بلا مهمّة مجدوَلة.
- الطالب يحذف بياناته بنفسه من الإعدادات ← صفّي، وتُحذف فعلًا لا تُخفى.

### الفِرَق

عمود `team` في جدول الطلاب، يضبطه **المعلّم وحده** — لا يستطيع الطالب أن يضع
نفسه في الفريق المتصدّر، ولا يصل شيء عن الفِرَق إلى جهازه. والتوزيع التلقائي
في اللوحة يوازن الفِرَق حسب التقدّم الحالي (snake draft)، فلا يبدأ فريق
متقدّمًا، ويقيس السباق جهد الأسبوع لا من صادف أن يكون مع من.

وسباق الفِرَق يحسب **معدّل الفرد في الفريق** لا مجموعه، حتى لا يفوز فريق من
تسعة على فريق من أربعة لمجرّد أنّه أكبر.

### ملاحظة نظاميّة

تخزين تقدّم طالب قاصر على خادم يجعلك معالجًا لبيانات شخصية تحت نظام حماية
البيانات الشخصية السعودي، مهما قلّت البيانات. ما سبق يقلّل ذلك إلى أدنى حدّ
عمليّ — لا اسم ولا وسيلة تواصل ولا معرّف ثابت للجهاز غير الذي يولّده الطالب
نفسه — لكنّه لا يُلغيه. قبل استخدام هذا مع فصل حقيقي في مدرسة: أبلِغ أولياء
الأمور، واجعل الانضمام اختياريًّا (وهو كذلك أصلًا).

## الاختبار محليًّا

```bash
npx wrangler d1 execute wordspark-db --local --file=./schema.sql
npx wrangler dev --local --port 8788
```

ثم `teacher.html?api=http://127.0.0.1:8788`.

`schema.sql` هو نفسه المطبَّق على الإنتاج حرفيًّا، فلا تنحرف النسخة المحلّية
عن الحقيقية.

## المسارات

| | | |
|---|---|---|
| `POST` | `/api/class` | أنشئ فصلًا ← `{code, teacher_key}` (المفتاح مرّة واحدة) |
| `GET` | `/api/class?code=` | عامّ: هل الرمز صحيح؟ العدد فقط، لا الكشف |
| `POST` | `/api/class/archive` | أغلق الفصل / أعِد فتحه — بالمفتاح |
| `POST` | `/api/join` | انضمام طالب — idempotent |
| `POST` | `/api/sync` | رفع التقدّم والأحداث |
| `GET` | `/api/roster` | كشف الفصل — بالمفتاح |
| `POST` | `/api/team` | توزيع الفِرَق — بالمفتاح |
| `POST` | `/api/learner/remove` | إخفاء طالب من اللوحة — بالمفتاح |
| `DELETE` | `/api/learner` | الطالب يحذف بياناته بنفسه |
| `GET` | `/api/health` | فحص |
